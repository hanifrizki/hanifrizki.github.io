# Hanif Rizki — academic website

This is a GitHub Pages / Jekyll website, retaining the original **Minimal Mistakes** remote theme.

## Deploy

1. Unzip this package.
2. Copy its contents (including `_data`, `_includes`, `assets`, and all `.md` files) to the root of the GitHub repository `hanifrizki.github.io`.
3. Commit and push to `main`.
4. In **GitHub → Settings → Pages**, choose **Deploy from a branch → main → /(root)** if not already configured.
5. Visit `https://hanifrizki.github.io/`. GitHub Pages may take a little time to rebuild; hard-refresh if the old favicon is cached.

## Customise

- Site details, author, portrait links: `_config.yml`
- Top navigation tabs: `_data/navigation.yml`
- Styles preserving the existing theme: `assets/css/portfolio.css`
- Browser-tab face icon: `favicon.ico`, `assets/favicon-32.png`, `assets/favicon-192.png`
- Content pages: `index.md`, `research.md`, `teaching.md`, `materials.md`, `cv.md`, `notes/index.md`
- Original PDF CV: `assets/files/Hanif_Rizki_CV_September_2026.pdf`

No additional theme installation is needed on GitHub Pages. Make sure Jekyll remote themes are supported by your chosen Pages build workflow.
